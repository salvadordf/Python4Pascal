Declaration

type TPyDateTimeModule = class(TImportedPyModule)

Description

TPyDateTimeModule imports the "datetime" module and gets several object types related to that module.

This class also includes several helper functions to create and convert "datetime" objects.

<see href="https://docs.python.org/3/library/datetime.html">See the article about the "datetime" module.)
