Public property Isolated : boolean read FIsolated write FIsolated;

If True, enable isolated mode: 

- Set safe_path to True: don't prepend a potentially unsafe path to
  sys.path at Python startup, such as the current directory, the
  script's directory or an empty string.
- Set use_environment to False: ignore PYTHON environment variables.
- Set user_site_directory to False: don't add the user site directory
  to sys.path.
- Python REPL doesn't import readline nor enable default readline
  configuration on interactive prompts.

Set to True by the -I command line option.

Default: False in Python mode, True in isolated mode.

<see href="https://docs.python.org/3/c-api/init_config.html#isolated-configuration">See the article about Isolated Configuration.)

Public property ParserDebug : boolean read FParserDebug write FParserDebug;

Parser debug mode. If True, turn on parser debugging output (for expert only, depending on compilation options).

Enabled by the -d command line option. Set to the PYTHONDEBUG environment variable value.

Needs a debug build of Python (the Py_DEBUG macro must be defined).

Default: False.

<see href="https://docs.python.org/3/using/cmdline.html#envvar-PYTHONDEBUG">See the article about PYTHONDEBUG.)

Public property Verbose : TPyVerboseMode read FVerbose write FVerbose;

Verbose mode. If pvmModule or pvmFull, print a message each time a module is imported, showing the place (filename or built-in module) from which it is loaded.

If pvmFull, print a message for each file that is checked for when searching for a module. Also provides information on module cleanup at exit.

Enabled by the -v command line option.

Set by the PYTHONVERBOSE environment variable value.

Default: pvmDisabled.

<see href="https://docs.python.org/3/using/cmdline.html#envvar-PYTHONVERBOSE">See the article about PYTHONVERBOSE.)

Public property Interactive : boolean read FInteractive write FInteractive;

If True, enable the interactive mode (REPL).

Enabled by the -i command line option.

Default: False.

Public property OptimizationLevel : TPyOptimizationLevel read FOptimizationLevel write FOptimizationLevel;

Compilation optimization level: 

- polDebug (0) : Peephole optimizer, set __debug__ to True.
- polRelease (1) : Level 0, remove assertions, set __debug__ to False.
- polReleaseNoDocStrings (2) : Level 1, strip docstrings.

Incremented by the -O command line option. Set to the PYTHONOPTIMIZE environment variable value.

Default: polDebug (0).

<see href="https://docs.python.org/3/using/cmdline.html#envvar-PYTHONOPTIMIZE">See the article about PYTHONOPTIMIZE.)

Public property SiteImport : boolean read FSiteImport write FSiteImport;

Import the site module at startup?

If equal to zero, disable the import of the module site and the site-dependent manipulations of sys.path that it entails.

Also disable these manipulations if the site module is explicitly imported later (call site.main() if you want them to be triggered).

Set to False by the -S command line option.

sys.flags.no_site is set to the inverted value of site_import.

Default: True.

Public property PathConfigWarnings : boolean read FPathConfigWarnings write FPathConfigWarnings;

If True, calculation of path configuration is allowed to log warnings into stderr. If False, suppress these warnings.

Default: True in Python mode, False in isolated mode.

Changed in version 3.11: Now also applies on Windows.

<see href="https://docs.python.org/3/c-api/init_config.html#init-path-config">Part of the Python Path Configuration input.)

Public property UseEnvironment : boolean read FUseEnvironment write FUseEnvironment;

Use environment variables?

Set to False by the -E environment variable.

Default: True in Python config and False in isolated config.

<see href="https://docs.python.org/3/using/cmdline.html#using-on-envvars">See the article about environment variables.)

Public property UserSiteDirectory : boolean read FUserSiteDirectory write FUserSiteDirectory;

If True, add the user site directory to sys.path.

Set to False by the -s and -I command line options.

Set to False by the PYTHONNOUSERSITE environment variable.

Default: True in Python mode, False in isolated mode.

<see href="https://docs.python.org/3/using/cmdline.html#envvar-PYTHONNOUSERSITE">See the article about PYTHONNOUSERSITE.)

Public property WriteBytecode : boolean read FWriteBytecode write FWriteBytecode;

If False, Python won't try to write .pyc files on the import of source modules.

Set to False by the -B command line option and the PYTHONDONTWRITEBYTECODE environment variable.

Default: True.

<see href="https://docs.python.org/3/using/cmdline.html#envvar-PYTHONDONTWRITEBYTECODE">See the article about PYTHONDONTWRITEBYTECODE.)

Public property ProgramName : string read FProgramName write FProgramName;

Program name used to initialize executable and in early error messages during Python initialization.

On macOS, use PYTHONEXECUTABLE environment variable if set.

If the WITH_NEXT_FRAMEWORK macro is defined, use __PYVENV_LAUNCHER__ environment variable if set.

Use argv[0] of argv if available and non-empty.

Otherwise, use "python" on Windows, or "python3" on other platforms.

<see href="https://docs.python.org/3/c-api/init_config.html#init-path-config">Part of the Python Path Configuration input.)

<see href="https://docs.python.org/3/using/cmdline.html#envvar-PYTHONEXECUTABLE">See the article about PYTHONEXECUTABLE.)

Public property ModuleSearchPaths : string read FModuleSearchPaths write FModuleSearchPaths;

A list of strings that specifies the search path for modules.

Initialized from the environment variable PYTHONPATH, plus an installation-dependent default.

Controls lazy import behavior. Accepts two values:
