Public class function Check(const aPyObject: IPyObject): boolean;

Return true if aPyObject is a list object or an instance of a subtype of the list type. This function always succeeds.

Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if aPyObject is a list object, but not an instance of a subtype of the list type. This function always succeeds.

Public class function New(len: Py_ssize_t): IPyObject;

Return a new list of length len on success, or nil on failure.

Note: If len is greater than zero, the returned list object's items are set to nil. Thus you cannot use abstract API functions such as TPySequence.SetItem() or expose the object to Python code before setting all items to a real object with TPyList.SetItem(). The following APIs are safe APIs before the list is fully initialized: TPyList.SetItem().

Public class function Size(const list: IPyObject): Py_ssize_t;

Return the length of the list object in list; this is equivalent to len(list) on a list object.

Public class function GetItem(const list: IPyObject; index: Py_ssize_t): IPyObject; overload;

Like TPyList.GetItemRef(), but returns a borrowed reference instead of a strong reference.

Note: In the free-threaded build, the returned borrowed reference may become invalid if another thread modifies the list concurrently. Prefer TPyList.GetItemRef(), which returns a strong reference.

Public class function GetItem(const list: IPyObject; const index: TVarData): IPyObject; overload;

Like TPyList.GetItemRef(), but returns a borrowed reference instead of a strong reference.

Note: In the free-threaded build, the returned borrowed reference may become invalid if another thread modifies the list concurrently. Prefer TPyList.GetItemRef(), which returns a strong reference.

Public class function GetItemRef(const list: IPyObject; index: Py_ssize_t): IPyObject; overload;

Return the object at position index in the list pointed to by list. The position must be non-negative; indexing from the end of the list is not supported. If index is out of bounds (<0 or >=len(list)), return nil and set an IndexError exception.

Added in version 3.13.

Public class function SetItem(const list: IPyObject; index: Py_ssize_t; const item: IPyObject): boolean; overload;

Set the item at index index in list to item. Return True on success. If index is out of bounds, return False and set an IndexError exception.

Note: This function "steals" a reference to item, even on error. On success, it discards a reference to an item already in the list at the affected position (unless it was nil).

Public class function GetSlice(const list: IPyObject; low, high: Py_ssize_t): IPyObject;

Return a list of the objects in list containing the objects between low and high. Return nil and set an exception if unsuccessful. Analogous to list[low:high]. Indexing from the end of the list is not supported.

Public class function SetSlice(const list: IPyObject; low, high: Py_ssize_t; const itemlist: IPyObject): boolean;

Set the slice of list between low and high to the contents of itemlist. Analogous to list[low:high] = itemlist. The itemlist may be nil, indicating the assignment of an empty list (slice deletion). Return True on success, False on failure. Indexing from the end of the list is not supported.

Note: In the free-threaded build, when itemlist is a list, both list and itemlist are locked for the duration of the operation. For other iterables (or nil), only list is locked.

Public class function Sort(const list: IPyObject): boolean;

Sort the items of list in place. Return True on success, False on failure. This is equivalent to list.sort().

Note: In the free-threaded build, element comparison via __lt__() can execute arbitrary Python code, during which the per-object lock may be temporarily released. For built-in types (str, int, float), the lock is not released during comparison.

Public class function Reverse(const list: IPyObject): boolean;

Reverse the items of list in place. Return True on success, False on failure. This is the equivalent of list.reverse().

Public class function AsTuple(const list: IPyObject): IPyObject;

Return a new tuple object containing the contents of list; equivalent to tuple(list).

Public class function Extend(const self_, iterable: IPyObject): boolean;

Extend list with the contents of iterable. This is the same as TPyList.SetSlice(list, PY_SSIZE_T_MAX, PY_SSIZE_T_MAX, iterable) and analogous to list.extend(iterable) or list += iterable.

Raise an exception and return False if list is not a list object. Return True on success.

Added in version 3.13.

Note: In the free-threaded build, when iterable is a list, set, dict, or dict view, both list and iterable (or its underlying dict) are locked for the duration of the operation. For other iterables, only list is locked; iterable may be concurrently modified by another thread.

Public class function Clear(const self_: IPyObject): boolean;

Remove all items from list. This is the same as TPyList.SetSlice(list, 0, PY_SSIZE_T_MAX, nil) and analogous to list.clear() or del list[:].

Raise an exception and return False if list is not a list object. Return True on success.

Added in version 3.13.
