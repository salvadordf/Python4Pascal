Declaration

type TPyDistribution = class(TObject)

Description

The interface of the distributions yielded by TPyMetadata.distributions() and friends.

Consumers should prefer this protocol over Distribution, as it is also satisfied by the objects that importlib.metadata supplies.

<see href="https://docs.python.org/3/library/importlib.metadata.html">See the article about importlib.metadata.)

<see href="https://importlib-metadata.readthedocs.io/en/latest/api.html#importlib_metadata._meta.IDistribution">See the IDistribution documentation.)
