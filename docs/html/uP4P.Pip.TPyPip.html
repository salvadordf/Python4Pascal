type TPyPip = class(TObject)

Description

TPyPip is a custom class created to use the pip utility which allows manage the installed packages in Python.

This class uses a TPySubprocess instance to run the pip utility.

<see href="https://docs.python.org/3.15/installing/index.html">See the article about Installing Python modules.)

<see href="https://packaging.python.org/en/latest/">See the article about the Python Packaging User Guide.)
