TPyVerboseMode = (...);

Python verbose mode

<see href="https://docs.python.org/3/c-api/init_config.html#c.PyConfig.verbose">See the article about Python Initialization Configuration.)

Values
  • pvmDisabled = 0: Verbose mode disabled.
  • pvmModule = 1: Print a message each time a module is imported, showing the place (filename or built-in module) from which it is loaded.
  • pvmFull = 2: Print a message for each file that is checked for when searching for a module. Also provides information on module cleanup at exit.
TPyOptimizationLevel = (...);

Compilation optimization level.

<see href="https://docs.python.org/3/c-api/init_config.html#c.PyConfig.optimization_level">See the article about Python Initialization Configuration.)

Values
  • polDebug = 0: Peephole optimizer, set __debug__ to True.
  • polRelease = 1: Level 0, remove assertions, set __debug__ to False.
  • polReleaseNoDocStrings = 2: Level 1, strip docstrings.
