Public class function AsBuffer(const ob: IPyObject): PByte;

Return a pointer to the contents of ob.

The pointer refers to the internal buffer of ob, which consists of len(ob) + 1 bytes.

The last byte in the buffer is always nil, regardless of whether there are any other nil bytes.

The data must not be modified in any way, unless the object was just created using TPyBytes.FromStringAndSize(nil, size).

It must not be deallocated. If o is not a bytes object at all, returns nil and raises TypeError.

soft-deprecated:: 3.15 Use the PyBytesWriter API instead of TPyBytes.FromStringAndSize(nil, len).

Public class function Repr(const ob: IPyObject; smartquotes: boolean): IPyObject;

Get the string representation of bytes. This function is currently used to implement bytes.__repr__() in Python.

This function does not do type checking; it is undefined behavior to pass bytes as a non-bytes object or nil.

If smartquotes is true, the representation will use a double-quoted string instead of single-quoted string when single-quotes are present in bytes. For example, the byte string 'Python' would be represented as b"'Python'" when smartquotes is true, or b'\'Python\'' when it is false.

On success, this function returns a strong reference to a str object containing the representation. On failure, this returns nil with an exception set.

Public class procedure Concat(const bytes_, newpart: IPyObject);

Create a new bytes object in bytes_ containing the contents of newpart appended to bytes_; the caller will own the new reference.

The reference to the old value of bytes_ will be "stolen". If the new object cannot be created, the old reference to bytes_ will still be "stolen", the value of bytes_ will be set to nil, and the appropriate exception will be set.

Note: If newpart implements the buffer protocol, then the buffer must not be mutated while the new bytes_ object is being created.

Public class procedure ConcatAndDel(const bytes_, newpart: IPyObject);

Create a new bytes object in bytes_ containing the contents of newpart appended to bytes.

This version releases the strong reference to newpart (i.e. decrements its reference count).

Public class function AsBufferAndSize(const ob: IPyObject; var buffer: PByte; var length: Py_ssize_t): boolean;

Return the contents of the object ob through the output variables buffer and length. Returns True on success.

The buffer refers to an internal buffer of obj, which includes an additional nil byte at the end (not counted in length). The data must not be modified in any way, unless the object was just created using TPyBytes.FromStringAndSize(nil, size). It must not be deallocated. If ob is not a bytes object at all, TPyBytes.AsBufferAndSize() returns False and raises TypeError.

Public class function Join(const sep, iterable: IPyObject): IPyObject;

Similar to sep.join(iterable) in Python.

sep must be Python bytes object. (Note that TPyUnicode.Join() accepts nil separator and treats it as a space, whereas TPyBytes.Join() doesn't accept nil separator.)

iterable must be an iterable object yielding objects that implement the buffer protocol.

On success, return a new bytes object. On error, set an exception and return nil.

Added in version 3.14.

Note: If iterable objects implement the buffer protocol, then the buffers must not be mutated while the new bytes object is being created.
