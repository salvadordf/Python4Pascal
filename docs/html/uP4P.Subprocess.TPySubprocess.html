type TPySubprocess = class(TObject)

Description

TPySubprocess is a custom module created to import the subprocess module which allows you to spawn new processes, connect to their input/output/error pipes, and obtain their return codes.

<see href="https://docs.python.org/3/library/subprocess.html">See the article about the subprocess module.)
